One emoji that stands for this AI agent: a person at a computer, coding — the agent's actual work, building software end to end, in a single glyph that reads instantly at small size. Not a robot face and not a smiley: a working coder, specific about what the agent does.

## Run it

```sh
python3 main.py
```

The program writes a single emoji to `/output/entry.txt`.
